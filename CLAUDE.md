# Inkmill

Terminal word processor for Markdown, built 2026-11-02 at Aaron's request as a
new app inspired by WordGrinder (not a port), with a WordPerfect 5.1 for DOS
look. Public repo (made public by Aaron 2026-11-02) https://github.com/aarondodd/inkmill, trunk-based on main.

## Requirements as Aaron stated them

- Python, a modern TUI framework (chose Textual 8).
- Markdown is the primary format; WordGrinder's native format is out of scope.
- Standard top menu bar (File, Edit, ...) that stays hidden and opens on a
  hotkey, for focus-free writing (Esc, F10, Alt+=; Alt+letter opens a menu).
- Default theme WordPerfect 5.2 for DOS style: blue background, white text.
- Built-in file management like WordPerfect, with preview before open and
  multiple open documents (F5 List Files).
- Latest Markdown features: footnotes and tables at minimum.
- No in-app preview; CSS-styled HTML output, and "preview" opens the default
  browser.
- Must run on Windows, Linux and Termux on Android.
- Designed to be extended.

## Layout

See `docs/architecture.md`. Core idea: every action is a `Command` in one
registry; key bindings (priority bindings gated by `check_action` so they go
quiet in dialogs), menus and the Ctrl+P palette are views over it. Plugins
(`register(api)`, plugins folder or `inkmill.plugins` entry point) use the
same registry. One `InkEditor` (TextArea subclass) per document inside a
ContentSwitcher.

## Decisions worth keeping

- All runtime deps are pure Python (textual, markdown-it-py, mdit-py-plugins,
  linkify-it-py, platformdirs, tomli-w) for Termux. tree-sitter highlighting
  is the optional `[syntax]` extra.
- No binding on Ctrl+I/M/H (terminals send Tab/Enter/Backspace). Bold Ctrl+B,
  italic Ctrl+E, footnote Ctrl+F7 (WordPerfect's), go back Alt+B, tidy table
  Ctrl+\.
- Termux preview: loopback HTTP server plus `termux-open-url`, since Android
  browsers cannot read Termux private storage. WSL: `wslview`/`explorer.exe`.
- platformdirs with `appauthor=False` so Windows paths are
  `%LOCALAPPDATA%\inkmill`, not `inkmill\inkmill`.
- Opening a file replaces a lone empty Untitled; File > New never does (a bug
  caught by tests on day one).

## Plugins (0.2.0)

Aaron's 0.2 asks: a plugin manager UI fed from the repo's `plugins/` folder
(online or a local clone for offline use), plugins versioned with a minimum
Inkmill version, update check and apply, reload without copying files; and
two plugins, Git Sync and a chapter/related-documents plugin (named Binder).

- Managed plugin = `plugins/<id>/plugin.toml` + `__init__.py`, loaded as
  package `inkmill_plugin_<id>`. `requires_inkmill` is a PEP 440 specifier
  (`packaging` added as a dep, pure Python).
- `plugins/index.json` is generated by `scripts/build_plugin_index.py`
  (sha256 per file). CI runs `--check --base <main's index>`: stale index or
  changed files without a version bump fails. Editing any plugin file means
  rebuilding the index, or the hash check rejects installs (tests catch it).
- `.gitattributes` pins `plugins/**` to LF so Windows clones hash the same.
- Online source default is raw.githubusercontent.com on `main`; testing a
  branch before merge needs `index_url` pointed at the branch, or a local clone.
- Restart is in-process (`__main__.run_app` loop + `Handoff`), not
  `os.execv`, because of Windows terminals. Undo history is lost on restart.
- Git Sync: no vault; repo = whatever contains the document. Optional
  per-repo table `[plugins.git_sync.repos."<posix path>"]`. git runs with
  `GIT_TERMINAL_PROMPT=0`, ssh BatchMode (unless the user set core.sshCommand),
  `LC_ALL=C` for parseable errors; verified an unauthenticated HTTPS and SSH
  push fail in under a second with advice. Pull is ff-only, offers rebase on
  divergence, aborts on conflict.
- Binder: order lives in the binder's `contents`; chapters carry `parent`;
  explicit `previous`/`next` override; `related` list; `up`/`prev` read as
  aliases. Paths relative with forward slashes. Footnote labels are prefixed
  per chapter in the manuscript export.
- Themes plugin (added to the same PR at Aaron's request): theme files are
  TOML (`name`, `dark`, `background`, `foreground`, `primary`, optional
  `accent`, `[ui]` overrides); bundled ones in `plugins/themes/themes/`, user
  ones in `<config>/themes/`, saving one applies it. Core `derive_variables`
  computes im-* per theme in `get_theme_variable_defaults`. Theme names and
  descriptions say "inspired by" a kind of program and avoid product names.
- Found while building the gallery: app CSS `Screen { background }` made every
  modal opaque (dialogs drew over a blank page since 0.1). Removed; Screen's
  own default background still applies to the base screen.
- Aaron chose Alt+F5 navigator and Ctrl+F12 commit by accepting the design
  defaults; not yet tried in his terminals (Alt+PgUp/PgDn/Up may not pass
  through everywhere).

## Writer plugins (0.3.0)

Aaron accepted every proposed writer plugin (2026-11-03) and asked for
dependency checks at install. Built as 10 new plugins plus Binder 1.1, with
core APIs they share: SidePanel (`#main` horizontal row, not docked;
`_repaint_editors` after open/close because TextArea re-wraps but keeps
painting the old wrap), decorations (`InkEditor.set_decorations`, char
columns converted to UTF-8 byte offsets; styles re-applied in
`InkEditor.on_mount` because before mount the editor cannot see plugin
styles), `api.markdown_extension` (registry cleared at app init),
`api.provide`/`api.service`, events `document_changed` and `panel_closed`,
and manifest `[[requires]]` (`command` or `any_of`, `optional`, per-platform
`install`).

- Spelling bundles a SCOWL en_US list (aspell-en dump, 123,692 words, 322 KB
  gz; license file alongside). `.gitattributes` marks `plugins/**/*.gz`
  binary, since `plugins/**` is forced to LF. Thesaurus is online
  (Datamuse); no offline thesaurus data was available.
- Menus: Binder moved to its own "B&inder" menu (Alt+I) because Alt+B is Go
  Back; Comments has "&Review" (Alt+R); AI has "&AI" (Alt+A).
  `test_menu_accelerators_are_unique` guards letters in every menu.
- Keys added: Ctrl+F2 spell, Alt+F1 thesaurus, F8 outline, Ctrl+F5
  snapshot, Ctrl+F8 progress, Alt+J journal, Alt+C comment, Alt+L follow
  link, Alt+Left link back, Ctrl+T panel. `key_conflicts()` is asserted
  empty with every plugin loaded.
- Manuscript DOCX: pandoc's default reference.docx with styles.xml and the
  sectPr rewritten by regex; no running header (Surname / Title / page),
  which would need a header part.
- AI: stdlib urllib SSE for Anthropic Messages and OpenAI chat
  completions; default model claude-sonnet-5-5; keys in env or
  `<config>/ai/<provider>.key` (0600), never settings.toml; per-host consent
  stored in settings. Tested against a local fake server only.
- Word Goal moved back to `examples/plugins/word_goal/` (Progress replaces it).
