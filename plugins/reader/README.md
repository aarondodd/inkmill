# Side Reader

Other documents beside the one you are writing, formatted and read-only in
the side panel. Pin your notes, an earlier chapter or the story bible, and
refer to them without leaving the text.

Shift+F4 (Document > Pin to Side Reader) pins the document you are in and
shows it in the reader; the cursor stays where it was. Switch back to the
document you are writing (F6 or Ctrl+L) and keep going. F4 (Document > Side
Reader) shows or hides the reader; with nothing pinned it lists the open
documents to choose from.

In the reader:

| Key | What it does |
|-----|--------------|
| Left and Right, [ and ] | The previous or next pinned document |
| L | List the open documents and read one (it is pinned) |
| U | Unpin the document shown |
| E, Enter | Edit the document shown |
| W | Widen the panel to half the screen, or back (remembered) |
| Up, Down, PgUp, PgDn | Scroll |
| Ctrl+T | Back to the text with the reader still open |
| Esc | Close the reader (F4 brings it back where you left it) |

The reader draws the document the way the reading view (Shift+F7) does:
headings, emphasis, lists, quotes, tables and code formatted, front matter
hidden. It shows the open document, unsaved changes included, and keeps
each document's scroll position while you page between them. Closing a
document unpins it. Web links open in the browser.
